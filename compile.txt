This source tree was tested with Microsoft Visual Studio 2026

Step 1:
--------
Use the clientr.sln file to open the solution

Step 1a:
--------
Generate your rsa_box files, see rsa.txt for instructions.

Step 2:
--------

Several dependencies are setup via vcpkg. The json file should be available and a
vcpkg install should download and build the packages. The x86 packages are currently
being used for this application.

Step 3:
--------

If everything is correct and working then after a couple of minutes you will have compiled
a working client under the 'dist' folder.
The build intermediate directory can be deleted 'dist/debug/src/' or 'dist/release/src/'
