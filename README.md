# netrekxp

This is a windows client for Netrek game that is based on the NetrekXP2009 source code. It has been updated to work with Visual Studio 2026.

## Description

Netrek is a multi-player battle simulation with a Star Trek theme. As a player, you captain starships to engage enemy vessels, bomb armies and invade planets in order to expand your team's space empire.

## Getting Started

View the [Netrek.org](https://www.netrek.org/) website for the most information.
* Binaries are located in the 'releases' section

### Executing program

* It is best to configure your own netrekrc file. The file is heavily commented but more information can be found in the [COW Reference Manual](https://www.netrek.org/clueguides/cowdocs/cow1998.html)
* Visit the [Netrek Newbie Manual](https://www.netrek.org/beginner/newbie.php) for information on game play.
<br />
Standard
```
netrek.exe
```

Specified netrekrc file
```
netrek.exe -r netrerc
```

Use specific server
```
netrek.exe -h 192.168.1.1
```


## Help

Command Line Options
```
Netrek XP 2026 1.0
Usage: netrek [options] [display-name]
Options:
 [-h servername]     specify a server
 [-p port number]    specify a port to connect to
 [-r defaultsfile]   specify defaults file
 [-s socketnum]      specify listen socket port for manual start
 [-U udp_port]       specify client UDP port (useful for some firewalls)
 [-F filename]       view recorded game from 'filename'
 [-f filename]       record game into 'filename' (filename is autogenerated if none is provided)
 [-l filename]       record messages into 'filename'
 [-L]                record messages into autogenerated log file with filename YYYYMMDD.log
 [-A]   character password
 [-C]   character name
 [-o]   use old style binary verification
 [-R]   use RSA binary verification
 [-P]   log server packets, repeat for increased information
 [-c]   run players check on the server
 [-m]   list servers, using UDP/IP to multiple metaservers
 [-M]   list servers, using TCP/IP to single metaserver
 [-k]   list servers from cache generated by -M
 [-D]   output debug info
 [-u]   show usage
 [-v]   display client version info
```
